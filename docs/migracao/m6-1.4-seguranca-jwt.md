## Decisões (Lucio + agente · 20/11)

| Tema | Decisão | Motivo |
|------|---------|--------|
| **Refresh token** | **Não** nesta Fase 1 | Superfície mínima (login + me). App trata **401** → `POST /api/mobile/auth/login` de novo. Refresh = backlog pós Fase 2 / G-M6 se jornada de campo exigir sessão longa sem re-digitar senha. |
| **Expiry access** | **480 min (8h)** | Alinhado a `Session.IdleTimeout` 8h do Core. Config: `Jwt:ExpiryMinutes`. `ClockSkew` validação = **1 min**. |
| **Audience / Issuer** | `Audience=rdo-apontador` · `Issuer=https://homolog.sistema.rdoapp.com.br` | Homolog only. Prod Core futuro = outro Issuer (não misturar chave). |
| **CORS** | Policy **`MobileJwt`** só em `/api/mobile/auth/*` | Origins: `https://homolog.sistema.rdoapp.com.br` + `localhost` / `127.0.0.1` (qualquer porta — Expo/Metro). **AllowAnyHeader/Method**. Sem cookies cross-origin (Bearer no header). |
| **Cookie SPA** | **Intacto** | `DefaultAuthenticate/Challenge/SignIn` = Cookies. JWT **não** vira default. Challenge JWT → **401 JSON** (nunca redirect HTML). |
| **SigningKey** | Só Staging/EC2 (não Git) | Placeholder no repo. Homolog smoke 1.2 já usou chave via SSM. **Proibido** commit de secret. |

---

## Comportamento esperado no Apontador (Fase 2)

1. Login → guardar `accessToken` + respeitar `expiresIn` (segundos).  
2. Chamadas Bearer: `Authorization: Bearer <token>`.  
3. **401** ou expiry → limpar token → tela login (ou re-login silencioso com credencial armazenada **só se** o app já fizer isso no cen. A — não inventar vault novo aqui).  
4. **Sem** endpoint `/refresh` até nova decisão documentada.
