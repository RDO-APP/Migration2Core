- `ESCOLHER-OBRA-BLANK-PAGE-SCENARIO-D-DIAGNOSIS.md`

1. **Easy Search**: All Escolher files start with `ESCOLHER-OBRA-`
2. **Clear Context**: File name tells you which page it's about
3. **Future Reference**: Easy to find related documentation
4. **Separation**: Page-specific vs global issues clearly separated
