- `ESCOLHER-OBRA-LIFE-SIGNS-DIAGNOSTIC-PLAN.md`

### Pattern for Global/Generic Documentation

```
{ISSUE-TYPE}-{DESCRIPTION}.md
```

**Examples**:
- `BLANK-PAGE-CRISIS-RESOLVED-FINAL.md` (affects all pages)
- `BLANK-PAGE-VIEW-COMPONENT-FIX-COMPLETE.md` (global header fix)

## ✅ BENEFITS OF THIS NAMING CONVENTION

### 1. Easy Tracking
- All Escolher-related files start with `ESCOLHER-OBRA-`
- Can quickly find all documentation for this page
- Easy to search: `ESCOLHER-OBRA-*`

- File name immediately tells you which page it's about
- No need to open file to know if it's relevant
- Reduces confusion when debugging

### 3. Future Reference
- When returning to fix issues later, easy to find related docs
- Historical context is preserved
- Pattern can be applied to other pages

### 4. Separation of Concerns
- Page-specific issues clearly separated from global issues
- Global fixes (like layout) kept separate
- Easier to understand impact of changes
